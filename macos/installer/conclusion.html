Instalação concluída

Próximos passos:

  1. Abra SonusGrid no Launchpad.
  2. Em Configuração, selecione a interface de rede plugada no switch Dante.
  3. Clique Aplicar e depois Iniciar.
  4. Em Ajustes do Sistema → Som aparece SonusGrid-Virtual. Selecione como saída para mandar áudio para a rede Dante.
  5. No Dante Controller rodando em outro PC, roteie os canais.

Documentação: /Applications/SonusGrid.app → menu Ajuda.
